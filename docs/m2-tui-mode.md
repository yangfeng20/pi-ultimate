# M2 TUI 模式

> 目标：让 Pi 的交互界面接近"完整 IDE 终端"，长输出可独立滚动、输入框固定。

## 痛点

- 默认模式下，模型长输出会把输入框挤走 / 需要频繁翻页回看。
- 想滚动到历史输出任意位置阅读，同时底部输入框还能正常输入，默认体验不佳。

## 解法：fullscreen 模式

Pi 支持 `fullscreen` TUI 模式：模型输出区域独立上下滚动，输入框（Editor）固定在终端最下方，类似 "Sticky" 输入框效果。

### 开启方式

写入全局配置 `~/.pi/agent/settings.json`：

```json
{
  "tuiMode": "fullscreen"
}
```

AI 引导时自动完成这一步（先备份原文件）。

### 效果

- 模型输出区可独立滚动，回看历史不丢输入框
- 输入框常驻底部，可随时输入
- 更贴近主流 Agent CLI（claude code / codex）的操作手感

## 其他 TUI 交互技巧

- `ctrl+o`：展开 / 收起工具调用详情
- 鼠标交互：部分版本支持点击查看单个调用详情（视版本而定）

## 验证

1. 重启 Pi 后确认界面为 fullscreen 布局
2. 滚动长输出，确认输入框不跟随滚动、仍可输入

> 不适应随时可改回：删掉 `tuiMode` 或改回默认值即可。
