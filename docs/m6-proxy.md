# M6 代理设置

> 目标：访问 GitHub / 国外资源不失败，但**不开全局代理**，不影响国内访问。

## 痛点

- 国内环境访问 GitHub、搜索、下载国外资源经常失败或超时。
- 开全局代理又会拖慢国内站点、影响公司内网，不划算。

## 解法：按需代理

### 方案 A：按命令生效（推荐）

把代理写进 AGENTS.md，让 AI 在需要访问国外资源时自动带上代理：

```
## 代理说明
- 访问国外资源（GitHub / 搜索 / 下载国外包）时，使用代理：
  https_proxy=http://127.0.0.1:7890
- 国内资源 / 内网直连，不带代理。
```

AI 引导时需要你提供：代理地址和端口（如 `127.0.0.1:7890`）。常见代理软件端口：Clash `7890`、V2Ray `10809`、Socks 等。

### 方案 B：环境变量（可选，对子进程生效）

写入 shell profile：

```bash
export https_proxy=http://127.0.0.1:7890
export http_proxy=http://127.0.0.1:7890
```

> ⚠️ 方案 B 影响所有子进程，国内站点可能变慢，按需选择。

## 验证

```bash
curl -x http://127.0.0.1:7890 -I https://github.com
# 期望：HTTP/2 200
```

## 无代理怎么办

没有代理软件？跳过本模块即可，不阻塞其他模块。搜索/下载国外资源可能失败，但国内开发场景基本够用。
