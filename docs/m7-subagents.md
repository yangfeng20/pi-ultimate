# M7 pi-subagents 插件 + sessionOnly 定时任务

> 目标：让子 agent 扛活（巡检、批量排查），定时任务按会话隔离，不串台。

## 痛点

- 定时任务默认任何 Pi 会话都可能抢到执行，结果出现在"另一个窗口"，排查问题像见鬼。
- 主会话干杂活，上下文越堆越大；想让子 agent 隔离干活但不会管理。

## pi-subagents 是什么

Pi 的子 agent 编排插件：主会话可以派发子 agent 干活（排查、巡检、批量处理），子 agent 有独立上下文，结束后汇报主会话。**定时任务（Schedule）依赖它承载。**

### 安装 / 升级

从 pi 官方扩展库安装（或更新）：

```bash
pi install pi-subagents
```

> sessionOnly 能力需要 **v0.62+**。低于此版本请升级：

```bash
pi update pi-subagents   # 或重装，以官方命令为准
```

## sessionOnly：仅当前会话执行

创建定时任务时加 `sessionOnly` 参数，任务只会被"创建它的那个会话"执行，其他会话自动跳过。

- **什么时候用**：巡检/值班类任务依赖会话上下文（需求链接、历史结论），换会话执行等于失忆。
- **怎么用**：对 Pi 说——
  ```
  创建一个定时任务，每 30 分钟巡检 <目标>，仅当前会话执行（sessionOnly）
  ```
- **配合**：与 M8 状态栏插件配合，可在 TUI 状态栏看到该任务的 ON/OFF 与下次执行时间。

## 定时任务创建规范（建议注入 AGENTS.md）

```
## 定时任务规范
- 创建定时任务时，默认确认是否"仅当前会话执行"（sessionOnly）。
- 巡检类任务：无新单静默，有新单才汇报。
- 子 agent 隔离：不同任务/单子放独立子 agent，主会话只做汇总。
```

## 验证

- `~/.pi/agent/extensions/` 中能看到 pi-subagents
- 创建一个一次性定时任务，确认只在创建会话执行、其他会话不执行
