# M8 pi-schedule-status 状态栏插件

> 目标：定时任务状态可视化，跑了没跑、下次何时执行一眼可见。

## 痛点

- 定时任务创建完就"失明"：跑了没跑？下次什么时候跑？执行中还是挂了？全靠猜。
- 多个定时任务互相不知道状态，出问题只能翻日志。

## pi-schedule-status 是什么

一个 Pi 状态栏插件，把当前会话的定时任务状态直接显示在 TUI 状态栏：

```
⏱ TAPD 需求缺陷自动巡检 ON | 下次 17:20
```

- 任务名 + ON/OFF 状态（带颜色区分）
- 下次执行时间
- 执行中状态（基于文件监听 + 定时兜底，低开销）
- 仅当前会话的任务只显示在当前会话（配合 M7 的 sessionOnly）

## 安装

从 pi 官方扩展库安装：

```bash
pi install pi-schedule-status
```

安装后**重启 Pi** 生效。

## 使用效果

创建任意定时任务后，状态栏自动出现对应条目：

```
⏱ <任务名> ON | 下次 17:20
⏸ <任务名> OFF | 已暂停
▶ <任务名> 执行中
```

## 验证

1. 安装并重启 Pi
2. 创建一个测试定时任务（如 10 分钟后的一次性任务）
3. 状态栏出现条目，时间正确倒计
4. 测试完删除任务，条目消失
